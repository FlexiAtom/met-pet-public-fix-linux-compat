# 可选：fidus 定位引擎 —— 只服务 Linux/Wayland 上「点击穿透切换时量窗口位置」那一格。
# 故意**不写成依赖**，也不要按名字 pip 它。三条理由（出处：fidus 的渠道裁定
# ~/.Athena/projects/meapet/pool/fidus-wheel-channel-direct-link.md）：
#   1) 只有 Linux 产物。Windows 没有 layer-shell 这条路，写进来那边就装不上（见下）。
#   2) 它不在任何索引里：PyPI、任何镜像、以及把 wheel 提交进本仓（vendor）都算二次分发，
#      发布方不为其行为负责 ⇒ `pip install fidus` 按名字解析不到，写版本号也没用。
#   3) 它的 `Requires-Dist: numpy>=1.24` 会让 pip 把 numpy 抬到 2.x，破掉本文件上面
#      `numpy<2` 那条 VITS 前提 ⇒ 只能 `--no-deps` 装单个文件。
# 版本号本身也别当抓手：`0.1.0b2` 是预发布，`>=0.1.0` 取不到它；`==0.1.0b2` 不需 `--pre`，
# 但那前提仍是索引里有这个名字，而它没有。
# 真取到之后**三步缺一不可**：钉完整 URL（tag 是身份第一来源）→ 同目录 .sha256 边车
# `sha256sum -c` → 读 `fidus.__git_commit__` 比对。只按版本号或只按文件名取都不算数。
# 这三步已落成一个命令（`meapet/fidus_channel.py`）：
#   "<本仓 python>" -m meapet.bootstrap --install-fidus
# 当前渠道**已定且链接已定**（2026-09-29 发布，资产在本机逐字节核验过）：
#   https://github.com/FlexiAtom/fidus/releases/download/v0.1.0-beta.2/fidus-0.1.0b2-cp310-abi3-manylinux_2_35_x86_64.whl
# 身份：__version__ 0.1.0-beta.2｜__git_commit__ v0.1.0-beta.2｜sha256
#   0b55463b118829d11cd3599bd01c34a507a2cd9c3ff9a541afa3d93f64bf7abb｜548,732 B｜glibc 下限 2.35（本机 2.44）。
# 本机实测到 CDN 只有约 6 KB/s，直链单发会超时 ⇒ 取件路径先走 api 资产路由、直链兜底，单次预算 300s。
